# 酒吧摇骰子游戏 - 产品设计方案

## 1. 游戏概述

**游戏名称**：吹牛骰 / 大话骰 (Liar's Dice)

**目标用户**：酒吧、KTV、朋友聚会场景的玩家

**核心玩法**：通过猜测场上骰子点数进行博弈，输者接受惩罚（喝酒）

---

## 2. 游戏规则

### 基础设定
- 玩家人数：2-6人
- 每人装备：5颗骰子 + 1个骰盅
- 骰子点数：1-6点

### 游戏流程
```
摇骰 → 看骰(只看自己) → 轮流叫点 → 开盅验证 → 判定输赢
```

### 叫点规则
| 术语 | 含义 | 示例 |
|------|------|------|
| 叫点 | "X个Y" | "3个4" = 场上至少有3个4点 |
| 加码 | 数量+1 或 点数+1 | "3个5" 或 "4个4" |
| 开 | 质疑上家 | 认为上家在吹牛 |

### 特殊规则
- **1点万能**：1点可当作任意点数（俗称"飞"）
- **叫斋**：宣布"斋X"后，1点不再万能，只算纯X点
- **起叫限制**：首轮叫点不能低于"场上人数×1"

### 输赢判定
```
开盅后：
  实际数量 >= 叫的数量 → 开的人输（喝酒）
  实际数量 <  叫的数量 → 叫的人输（喝酒）
```

## 3. 功能模块

### 核心功能
1. **摇骰动画** - 真实物理效果
2. **骰盅交互** - 掀盖看骰、遮挡对手
3. **叫点系统** - 快捷选择 + 语音播报
4. **开盅结算** - 动画展示 + 输赢判定
5. **惩罚系统** - 喝酒计数/自定义惩罚

### 辅助功能
- 房间系统（创建/加入）
- 好友对战 / 随机匹配
- 历史战绩
- 音效/震动反馈

## 6. 多人房间系统设计

### 6.1 房间创建流程

```
首页 → 创建房间 → 设置参数 → 生成房间码 → 等待玩家 → 开始游戏
                     ↓
              [房间人数: 2-6人]
              [AI玩家数: 0-5个]
              [AI难度: 简单/普通/困难]
              [是否公开: 是/否]
```

### 6.2 房间参数设置

| 参数 | 选项 | 默认值 |
|------|------|--------|
| 总人数 | 2-6人 | 4人 |
| AI数量 | 0 ~ (总人数-1) | 0 |
| AI难度 | 简单/普通/困难 | 普通 |
| 房间类型 | 私密(房间码)/公开(随机匹配) | 私密 |
| 每轮时限 | 15s/30s/60s/无限制 | 30s |

### 6.3 AI 行为设计

#### AI 决策逻辑

```
AI回合开始:
  ├─ 50% 概率 → 叫牌
  │     ├─ 根据自己骰子计算安全叫法
  │     ├─ 简单AI: 随机加码
  │     ├─ 普通AI: 基于概率计算
  │     └─ 困难AI: 记忆历史叫牌 + 概率推算
  │
  └─ 50% 概率 → 开盅
        └─ 判断当前叫点是否可信
```

#### AI 难度差异

| 难度 | 叫牌策略 | 开盅策略 | 特点 |
|------|----------|----------|------|
| 简单 | 随机加码，不考虑概率 | 随机开盅 | 容易被骗 |
| 普通 | 基于自己骰子+概率 | 叫点超过期望值时开 | 正常对手 |
| 困难 | 记忆所有叫牌+推算对手 | 精确计算开盅时机 | 难以欺骗 |

### 6.4 房间状态机

```
[等待中] ──玩家就绪──→ [游戏中] ──回合结束──→ [结算中]
    ↑                      │                    │
    │                      │                    │
    └──────────────────────┴────下一局──────────┘
```

## 7. 技术架构 (多人版)

### 前端架构
```
React + TypeScript + Vite
├── 状态管理: Zustand
├── 实时通信: Socket.io-client
├── 路由: React Router
└── UI: TailwindCSS
```

### 后端架构
```
Node.js + Express + Socket.io
├── 房间管理: 内存 + Redis
├── 游戏逻辑: 服务端验证
└── AI引擎: 独立模块
```

### 通信协议

| 事件 | 方向 | 数据 |
|------|------|------|
| create_room | C→S | {totalPlayers, aiCount, aiDifficulty} |
| join_room | C→S | {roomCode} |
| player_ready | C→S | {} |
| game_start | S→C | {players, currentTurn} |
| roll_dice | S→C | {myDice: [1,3,4,4,6]} |
| make_bid | C→S | {count, value} |
| bid_made | S→C | {playerId, count, value} |
| call_bluff | C→S | {} |
| round_result | S→C | {allDice, winner, loser} |
